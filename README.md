# Preços Proclin

Preços dos concorrentes da Dental Proclin, para a extensão do Chrome **Preços Proclin** usada pelos vendedores no VendAi.

- `precos.json`: atualizado todo dia útil pela rotina da Proclin (6h52). Só o nosso preço e o preço de cada concorrente, com o link. Sem custo, margem, estoque ou vendas.
- `extensao/`: a extensão do Chrome.

## Como instalar a extensão (uma vez, em cada notebook)

1. Baixe este repositório: botão verde **Code** → **Download ZIP**. Descompacte numa pasta fixa (ex.: `Documentos\precos-proclin`). Não apague essa pasta depois.
2. No Chrome, abra `chrome://extensions`.
3. Ligue o **Modo do desenvolvedor** (canto superior direito).
4. Clique em **Carregar sem compactação** e escolha a pasta `extensao` que está dentro da pasta descompactada.
5. Abra o VendAi (ou recarregue a página). Pronto.

Os preços se atualizam sozinhos todo dia, sem reinstalar. Quando houver versão nova da extensão, repita os passos 1 e 4 e clique em **Atualizar** em `chrome://extensions`.

## Como usar

- No pedido/cotação, cada produto ganha uma etiqueta com o menor concorrente: **vermelha** se estamos mais caros, **verde** se somos o menor.
- Clicando na etiqueta, ou abrindo "Detalhes do produto" ou o cadastro do produto, aparece o quadro **Concorrentes** com todas as lojas, o preço e o link **↗** para conferir no site.
- **✎ corrigir**: se o link de uma loja não é o mesmo produto, marque e envie. A Renata confere e corrige.
